# DrupalJira Custom Modules

This directory contains custom modules developed specifically for the DrupalJira project.

## Modules

### drupaljira_board

Provides the project task board, task status updates, task modal, and Scrum-specific Sprints functionality.

### drupaljira_timelog

Provides time tracking functionality, including the TimeLog entity, time logging forms, project statistics, and related services.

## Development

Custom modules are managed in Git and should be placed in this directory.

Module configuration is exported to `config/sync` when applicable.
